# CHEM M.5 EXAM QUEST

แอปเว็บแบบ Static สำหรับฝึกทำข้อสอบวิชาเคมีเพิ่มเติม 3 ชั้น ม.5 จำนวน 50 ข้อ

## ใช้งานบน GitHub Pages

1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลด `index.html`, `style.css` และ `app.js` ไว้ที่รากของ Repository
3. เปิด **Settings → Pages**
4. เลือก **Deploy from a branch**, สาขา `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
5. รอประมาณ 1–3 นาที จากนั้นเปิด URL ที่ GitHub แสดง

แอปทำงานบนเบราว์เซอร์โดยไม่ต้องมีฐานข้อมูล คะแนนสูงสุดบันทึกเฉพาะในอุปกรณ์ด้วย `localStorage` และหน้าสรุปผลสามารถพิมพ์หรือบันทึกเป็น PDF ได้
