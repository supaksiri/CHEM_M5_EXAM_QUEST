# CHEM RATE QUEST

เว็บแอปแบบทดสอบหลังเรียน เรื่อง **ปัจจัยที่มีผลต่ออัตราการเกิดปฏิกิริยาเคมี** สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 5

## คุณสมบัติ

- ข้อสอบปรนัย 4 ตัวเลือก จำนวน 20 ข้อ แบ่งเป็น 4 หัวข้อ หัวข้อละ 5 ข้อ
- มีคำใบ้และคำอธิบายเฉลยทุกข้อ
- มีกราฟประกอบโจทย์การแปลความหมายอัตราปฏิกิริยาและพลังงานก่อกัมมันต์
- เลือกเล่นแบบ 4 หัวใจหรือ 3 หัวใจ
- ตอบผิดเสียหัวใจ 1 ดวง หากหัวใจหมดต้องเริ่มใหม่ตั้งแต่ข้อ 1
- แสดงคะแนนรวม คะแนนรายหัวข้อ จำนวนหัวใจคงเหลือ และจำนวนครั้งที่ใช้คำใบ้
- ทุกกรณีเข้าสู่หน้าสรุปผล ทั้งทำครบ 20 ข้อและหัวใจหมดระหว่างทาง
- หน้าสรุปผลแสดงจำนวนข้อที่ตอบ คะแนนรวม คะแนนรายหัวข้อ หัวใจคงเหลือ และจำนวนครั้งที่ใช้คำใบ้
- หน้าผลลัพธ์รองรับการแคปหน้าจอและกดพิมพ์/บันทึกเป็น PDF
- ใช้งานได้บนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์

## วิธีเปิดใช้งานทันที

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

## วิธีเผยแพร่ผ่าน GitHub Pages

1. สร้าง repository ใหม่ใน GitHub เช่น `chem-rate-quest`
2. อัปโหลด `index.html`, `styles.css` และ `app.js` ไว้ที่หน้าหลักของ repository
3. เปิดเมนู **Settings → Pages**
4. ที่ **Build and deployment** เลือก **Deploy from a branch**
5. เลือก Branch เป็น `main` และ Folder เป็น `/ (root)` แล้วกด **Save**
6. รอประมาณ 1–3 นาที แล้วเปิดลิงก์ GitHub Pages ที่ระบบแสดง

## การแก้ไขข้อสอบ

เปิดไฟล์ `app.js` แล้วแก้ข้อมูลในตัวแปร `questions` แต่ละข้อประกอบด้วย:

- `text` คำถาม
- `options` ตัวเลือก 4 ข้อ
- `answer` ลำดับคำตอบที่ถูก เริ่มนับจาก 0
- `hint` คำใบ้
- `explain` คำอธิบายหลังตอบ
- `visual` กราฟประกอบ (ถ้ามี)

สร้างโดย คุณครูสุพักตร์ศิริ พืชสิงห์ โรงเรียนโพธิ์ศรีสว่างวิทยา
